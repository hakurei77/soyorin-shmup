流程：加图（可多选）→ 在图片队列里切换 → 选帧 → 写动作名 → 调好帧率 →「添加动作」入队， 重复多次后点「导出全部动作」，所有动作的帧按入队顺序拼成一张条带 + 一个 json（animations: { 动作名: { start, length, fps } }）。
每个动作的帧率独立：入队时取当前帧率滑块的值，不同动作可以不同； json 顶层的 fps 是缺省值，只对没写 fps 的旧条目生效。
同名动作 = 覆盖为新帧；队列里的动作可点 × 移除。
抠图采用边缘泛洪——只去除与帧边缘相连的白色背景， 角色内部的白色（白袜子、眼白等）会保留；阈值可直接输入数字精调。
「加载现有配置」选择旧的 xxx.json，再选择对应的旧条带 png， 新动作会追加在旧条带末尾。
「设置导出目录」选一次目标文件夹（如 soyorin-shmup/src/assets/frame， 或游戏素材目录 soyorin-shmup/public/、main-site/public/stg/）后会记住它， 之后点导出直接写入不再弹窗；「忘记目录」可重新设置。 不支持的浏览器回退为分别下载两个文件。
游戏侧：loadout.ts 中 sprite 填 json 路径（如 '/stg/player.json'）， 图片路径写在 json 的 image 字段里（换图只改 json）； 代码里按动作名调用——左移自动播 left、右移 right、其余 move，新增动作无需改游戏代码。
