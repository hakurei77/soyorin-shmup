# tools/

本目录存放 soyorin-shmup 的**独立开发工具**。

这些工具与游戏构建体系完全解耦：

- 不会被 Vite 打包（不在 `src/` import 链中，也不复制进 `dist/`）
- 不参与 `vue-tsc` 类型检查（`tsconfig.json` 的 `include` 不含本目录）
- 不会同步到 main-site
- 均为纯静态单文件，**直接用浏览器打开即可使用**，无需安装依赖、无需启动服务

## sprite-tool/

序列帧素材处理工具（单文件 `index.html`），用于制作自机皮肤：

1. **切割**：上传 4×4 网格白底图，自动裁成 16 帧
2. **抠图**：边缘泛洪去白底（保留角色内部的白色，如白袜子），阈值可调
3. **组动作**：勾选帧 → 命名动作（如 `move` / `right`）→ 设置该动作独立帧率 → 加入动作队列；支持多图混拼
4. **导出**：生成一张横向条带 `png` + 一个描述 `json`（含 `image`、`frameWidth`、`frameHeight`、`animations: { 动作名: { start, length, fps } }`）

### 导出位置

点「设置导出目录」选一次本项目的 `src/assets/frame/`，工具会通过 IndexedDB 记住该目录，之后导出直接写入，无需重复选择（浏览器安全限制，路径无法在代码中写死，必须亲手选一次）。

### 游戏内使用

导出到 `src/assets/frame/` 后，经 `import.meta.glob` 编译期打包，在角色配置（`src/config/loadout.ts`）中通过 `frame:` 协议引用：

```ts
sprite: 'frame:player' // 对应 src/assets/frame/player.json + player.png
```

游戏动作约定：移动播 `move`，按 D 播 `right`，按 A 播 `right` 并水平镜像。

## green-key-tool/

绿幕抠图工具（单文件 `index.html`），直接把绿底图抠成透明 png：

1. **拖拽**绿色背景图片进页面（或点击选择）
2. **抠图**：按像素与键色的加权色差（绿色通道权重高）判定背景；「抠除强度」调阈值，「边缘柔化」产生半透明过渡带，可勾选去除绿边溢色；背景不是纯绿时点原图拾取颜色
3. **预览**：右侧棋盘格背景实时显示透明结果
4. **保存**：与 sprite-tool 相同的目录记忆机制——「设置保存目录」选一次本文件夹后，之后点保存直接写入（浏览器安全限制，无法免授权直写 html 所在目录），不支持的浏览器回退为下载

## png2svg-tool/

PNG 转 SVG 工具（单文件 `index.html`），把绿幕图抠掉背景后描摹成矢量 svg：

1. **抠图**：拖入绿幕图，按 green-key-tool 相同的绿色加权色差去背景，可点原图拾取键色、调抠除强度/边缘柔化/去溢色
2. **矢量化**：缩放到尺寸上限 → 中位切分法把颜色量化到指定色数 → 每个颜色沿像素边界描摹闭合轮廓 → Douglas-Peucker 抽稀平滑 → 生成 svg path（`fill-rule="evenodd"` 处理镂空）
3. **调参**：颜色数、平滑度、最小色块面积（过滤杂点）、尺寸上限、裁剪到内容、描边防缝（防相邻色块简化后露细缝）
4. **保存**：与另两个工具相同的目录记忆机制，输出 `.svg`；不支持的浏览器回退为下载

适合扁平色块、轮廓清晰的素材（logo、像素画放大、简单立绘）；照片类图建议调低尺寸上限和颜色数。

## audio-trim-tool/

音频截断工具（单文件 `index.html`），纯前端截取音频片段：

1. **加载**：拖入或点击选择音频文件（mp3 / wav / ogg / m4a / flac 等浏览器可解码格式）
2. **选区**：波形图上拖拽框选保留区间，拖动两端绿色手柄微调，或直接输入起点/终点秒数（精确到毫秒）
3. **试听**：可试听选区或全曲，红色播放头实时指示位置
4. **导出**：选区无损切片（按采样帧裁剪，不重编码），导出为 16-bit PCM `.wav` 下载，文件名自动带上起止时间

不依赖网络与服务器，音频数据不离开本地。
