浏览器安全限制：无法直接写入本 html 所在文件夹，「设置保存目录」选一次本文件夹（tools/green-key-tool） 后会通过 IndexedDB 记住它，之后点保存直接写入不再弹窗；不支持的浏览器回退为下载。
抠图模式：绿底用绿色加权色差，白底用等权色差（键色自动设为纯白）；自定义可点左侧原图拾取任意背景色。
抠图原理：按像素与键色的色差决定透明度——色差小于「抠除强度」判为背景； 「边缘柔化」让过渡带半透明，避免生硬锯齿；「去除边缘溢色」把残留反光压回中性色。
高光保护：白底抠图时，角色身上的亮部（如高光、浅色服饰）容易被误判为背景。 该项按饱和度区分——接近纯白且低饱和的判为背景，带有明显色彩的亮像素会被保留。 数值越大保护越强（0=关闭）。若仍有高光被抠，可适当调低「抠除强度」或调高「高光保护」。
最小扣除面积：按 4 连通把候选背景分块，只有面积达到该值的相连大块才会被扣除。 角色身上零散的小白点、细小高光因面积不足会被完整保留；0=关闭该过滤（所有候选背景都扣）。 建议从 1000 起，按图分辨率上调。
