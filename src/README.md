## 一、游戏定位

- **类型**：二次元 × 科幻 × 赛博朋克 STG 弹幕射击（纵版卷轴，东方 Project 式高密度弹幕玩法，科幻军事题材包装）
- **视角/操作**：俯视角自机 + 鼠标瞄准射击 + WASD 移动，含低速精密移动、判定点显示、闪现（Dash）
- **氛围关键词**：星海、霓虹、机娘、脑机接口、巨企军工、佣兵拾荒、华丽弹幕
- **技术形态**：Web 游戏（Vue 3 + Canvas 2D 引擎），全中文文案

一句话概括：**开着机娘在霓虹星海里穿弹幕的二次元佣兵物语。**

## 三、视觉风格规范

### 3.1 总体美术方向

- **二次元赛璐璐（Cel-shading）**：粗黑轮廓线 + 平涂色块 + 简单明暗二分阴影，轻微卡通化比例，干净矢量感，**禁止写实材质渲染与渐变堆砌**
- **科幻霓虹**：深色太空底 + 高饱和发光体（弹幕、光束、能量管线、UI 辉光）
- **UI 风格**：深色玻璃拟态（毛玻璃模糊面板 `rgba(12,12,28,0.55)` + 细白边），主色调为**紫色系**：
  - 主强调色 `#bb99f5`（喵奈机身主色）
  - 辅强调色 `#f0abfc`（描边/高光）
  - 标题带紫色霓虹 text-shadow 辉光
- 定义位置：`styles/stg-vars.scss`、`styles/stg-common.scss`
