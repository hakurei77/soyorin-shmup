# 代达罗斯工坊（Daedalus Atelier · DA）

## 公司风格说明

代达罗斯工坊，星际时代最神秘的顶级定制义体工坊，不为市场生产，只为委托人雕琢。

如果说奥林匹斯贩卖的是身份，伏尔甘贩卖的是火力，那么代达罗斯贩卖的，是"独一无二"本身。这家工坊没有量产线、没有目录、没有门店——只有一间藏在义体之城旧区深处的作坊，和一份据说要等上三年的委托名单。每一件代达罗斯义体都从零开始为委托人单独设计：象牙白的陶瓷装甲按委托人的骨相手工塑形，玫瑰金的骨架依照其神经图谱逐节调校，暖琥珀色的光脉亮度甚至可以随佩戴者的心跳呼吸起伏。工坊的每一件成品内侧都蚀刻着同一行小字："此物，世上仅此一件。"

### 设计理念

- **定制即信仰**：代达罗斯从不做"适配"，只做"生长"。义体的每一条曲线都源于委托人的身体扫描与审美访谈，交付时不像装上去的零件，更像长出来的器官。
- **工艺即奢华**：象牙白陶瓷、玫瑰金骨架、手工蚀刻的卷草纹与珐琅嵌饰——代达罗斯的义体更像珠宝与钟表，而非工业制品。磨损不被视为损耗，而被视为"包浆"，工坊甚至提供终身养护服务。
- **杰作即姓名**：以传说中最伟大的造物与杰作命名——伊卡洛斯之翼、塔罗斯巨人、阿里阿德涅之线……每一件义体，都是工坊史上的又一件杰作。

### 企业文化

代达罗斯工坊的坊训是：**"你的身体，值得一件杰作。"**

工坊的首席工匠据说从不露面，只通过代理人接待委托人。委托流程近乎仪式：三次面谈、两轮神经测绘、一次审美对谈，之后是长达数月的等待。坊间传闻，工坊每年拒绝的委托比接受的还多——不是因为价格，而是因为"委托人不懂自己想要什么"。他们的标志——一对以齿轮与羽毛交织而成的羽翼——从不印在广告上，只烙在成品的内侧，只有佩戴者自己知道它在那里。

### 标志释义

代达罗斯工坊的徽标由两个元素构成：中央是一对**展开的羽翼**，象征代达罗斯为伊卡洛斯打造的那双翼；羽翼的每一根羽毛都由**精密齿轮与蚀刻纹路**构成，象征手工工艺与机械精密的合一。标志以象牙白为底、玫瑰金为主光、暖琥珀为辅光——白色是陶瓷与画布，金色是匠心与温度，琥珀是义体里流淌的生命之光。

### 产品特点

| 维度 | 说明 |
| ---- | ---- |
| 结构 | 象牙白陶瓷装甲壳，玫瑰金精调骨架，模块化可替换饰板 |
| 功能 | 全身神经测绘定制、触觉反馈保留、可随委托人需求终身改装 |
| 光效 | 暖琥珀色呼吸光脉，珍珠白微型指示灯，光强可随心律调节 |
| 外观 | 高定工坊风：象牙陶瓷 + 玫瑰金骨架 + 手工蚀刻卷草纹 + 珐琅嵌饰 |
