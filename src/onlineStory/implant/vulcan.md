# 伏尔甘军械（Vulcan Armaments · VA）

## 公司风格说明

伏尔甘军械，星际时代最臭名昭著的进攻性义体制造商，军工复合体中最激进的一把尖刀。

如果说奥林匹斯把义体做成奢侈品，伏尔甘就把义体做成军火。他们的产品不讲究优雅，只讲究杀伤：粗粝的炮钢灰装甲板上铆钉外露，灼红的散热格栅后面是永不停歇的轰鸣，熔橙色的能量管线像烧红的钢筋一样盘踞在义体表面。每一台伏尔甘义体出厂前都要在测试场上打空三个弹匣——用义体自己。在义体之城的地下黑市，流传着一条铁律：想活命，买奥林匹斯；想杀人，买伏尔甘。

### 设计理念

- **暴力即美学**：伏尔甘的义体拒绝隐藏杀意。外露液压杆、警示条纹、散热格栅、过载泄压阀——每一处结构都在昭告同一件事：这东西是用来摧毁的。
- **熔炉即血脉**：熔橙与灼红的能量管线贯穿义体全身，仿佛刚从锻炉里夹出的钢胚。功率越高，管线越亮——敌人亲眼看着自己被打死之前，会先看到伏尔甘亮起的光。
- **传说即武器**：以各大神话中的传奇兵器与战争巨兽命名产品线——伏尔甘贩卖的不是义体，是握在手里的传说。

### 企业文化

伏尔甘军械的厂训是：**"火力不足，是唯一的故障。"**

他们的工厂本身就是一座巨型熔炉，测试场的爆炸声二十四小时不停。伏尔甘的工程师有句口头禅："能加的装甲就加，能超的频就超，炸了就再造一台。"他们的标志——一柄砸进熔炉的锻锤，锤面迸出赤红火星——被烙在每一件义体的装甲板上，像一枚烫伤的印记。

### 标志释义

伏尔甘军械的徽标由两个元素构成：中央是一柄**锻锤**，象征火神伏尔甘的锻造神权；锻锤下方是一座**迸溅火星的熔炉**，象征永不停歇的战火与产能。标志以炮钢灰为底、熔橙为主光、警示黄为辅光——灰色是炮管与装甲，橙色是熔炉与过载，黄色是危险告急。

### 产品特点

| 维度 | 说明 |
| ---- | ---- |
| 结构 | 炮钢灰重型装甲板，铆接拼接，外露液压杆与机械连杆 |
| 功能 | 火力增幅、过载超频、后坐力缓冲，纯进攻性军用规格 |
| 光效 | 熔橙 / 灼红能量管线与散热格栅辉光，警示黄状态指示灯 |
| 外观 | 粗犷军工风：炮钢装甲 + 铆钉接缝 + 熔橙能量管 + 黄黑警示条纹 |

## 命名规范

- 格式：`VA-编号：名称`
- `VA` = Vulcan Armaments（伏尔甘军械）
- 使用数字编号，如 `VA-01`
- 名称主题：以「传说兵器与战争巨兽」中的神兵、凶兽、战魂命名（朗基努斯、冈格尼尔、芬里尔……），呼应"传说即武器"的理念
