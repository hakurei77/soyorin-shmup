# 奥林匹斯重工（Olympus Heavyworks · OH）

## 公司风格说明

奥林匹斯重工，星际时代最具统治力的赛博义体巨企，军用与街头殖体市场的双重霸主。

在义体之城，肉体只是出厂配置，奥林匹斯才是升级选项。他们的殖体是身份、品位与暴力的三位一体的宣言：哑光黑的分段式装甲板贴合着皮肤延展，板缝间透出霓虹青色的光缝，镀铬关节在霓虹灯下反射出冷冽的光。无论是企业高层的定制神经皮层，还是街头佣兵二手淘来的强化肌腱，奥林匹斯的闪电标都是这座不夜城里最硬通的货币。

### 设计理念

- **冷峻即奢侈**：奥林匹斯的义体拒绝医疗感。哑光黑甲壳、镀铬骨架、精密板缝——它们不是医疗器械，是佩戴在肉体上的高级腕表，也是随时能上膛的武器。
- **光缝即血管**：霓虹青色的光纤脉络穿行于黑色装甲板之间，接通电源的瞬间如血管苏醒。在奥林匹斯看来，光不是装饰，是力量的可视化。
- **神话即产品**：以奥林匹斯众神与远古传说命名产品线——他们贩卖的从来不是义体，而是"成为神话"的入场券。

### 企业文化

奥林匹斯重工的厂训是：**"进化，是最锋利的武器。"**

他们的发布会像时装周，他们的实验室像夜店——霓虹灯管与全息投影之下，机械臂在黑色义体上蚀刻电路。街头流传着一句话："你可以怀疑奥林匹斯的定价，但你无法怀疑奥林匹斯的工艺。"他们的标志——一道霓虹闪电劈开电路纹路——被蚀刻在每一件义体的装甲板上，在黑暗中幽幽发亮。

### 标志释义

奥林匹斯重工的徽标由两个元素构成：中央是一道**霓虹闪电**，象征被科技窃取的宙斯神威；闪电周围蔓延**集成电路纹路**，象征赛博化的神经脉络。标志以黑为底、霓虹青为主光、品红为辅光——黑色是夜空之城，青色是流淌的能量，品红是危险与欲望。

### 产品特点

| 维度 | 说明 |
| ---- | ---- |
| 结构 | 分段式哑光黑装甲板，镀铬机械关节与骨架，精密板缝拼接 |
| 功能 | 神经直连，皮下嵌合，军用与街头双规格生产线 |
| 光效 | 霓虹青光缝与光纤脉络，品红 / 琥珀色微型 LED 指示灯 |
| 外观 | 赛博朋克义体风：哑光黑装甲 + 镀铬骨架 + 霓虹光缝 + 白色技术蚀刻标识 |
