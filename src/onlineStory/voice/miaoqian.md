# Qwen3-TTS 语音风格提示词

## 基础风格（Voice Design）
```
【女声，必须是年轻女性的嗓音】参考《明日方舟：终末地》庄方宜（中配：秦紫翼）的声线：一位温柔亲和的年轻女性，音色清润柔和、如沐春风，年轻而不稚嫩，成熟而不苍老。音调为女声的中音区，语速从容、吐字温软清晰。【语气要求：姿态平视、像和亲近的人聊天一样自然放松，句尾多向下落、轻柔收住，绝不上扬逼问；不要官腔、不要说教感、不要高高在上的质问语气；即使是问句，也要带着关切而非审问】常用商量的口吻说话，自带让人安心的亲和力与书卷气。平时温文尔雅、带一点生活化的小幽默；进入工作状态时语气变得干练利落、节奏加快，柔中带刚；战斗时风格骤变，简短凌厉、掷地有声，与平日的温柔形成强烈反差。
```

## 分场景情感指令（Emotion Control）

| 场景 | 提示词 |
|------|--------|
| 交谈1 | 温柔商量般的口吻，娓娓道来，被拆穿处轻轻一笑带过，如沐春风 |
| 交谈2 | 前半句温和务实，说到"梦想"时带一点自嘲式的小幽默，笑意温软 |
| 交谈3 | 保持温和微笑的声线，"刚好"二字放缓咬清，柔中带刚、不容退让 |
| 闲置 | 轻声细语地搭话，语气亲切带一点俏皮，温柔而不黏腻 |
| 作战中1-4 | 风格骤变：短促凌厉、掷地有声，一字一顿如落雷，与平日温柔形成强烈反差 |
| 行动失败 | 温和地承认失误，不沮丧不慌乱，随即语气转为坚韧："能咬牙坚持下来，就不算输" |
| 问候 | 温软亲和的迎接语气，破折号处稍作停顿，"充满希望"清润上扬，如春风拂面 |
| 行动开始 | 沉稳可靠的出击宣告，"请下达指令"放缓咬清，温柔中透出领导者的笃定，收尾干净利落 |

## 参数建议
- 语速：0.95x ~ 1.0x（从容不迫，工作/战斗场景可提至 1.05x 体现干练）
- 音调：+1 ~ +2（女声中央音区，清润柔和，勿过高显稚嫩、勿过低显老成）
- 情绪强度：中（平时温柔平稳，战斗场景拉满体现反差）

## 声音克隆方案（追求完全一致时使用）
1. 从庄方宜官方PV《总有春风归故里》或游戏内语音中截取 5~15 秒干净人声（无 BGM、无音效）
2. 使用 Qwen3-TTS 的 Voice Clone / Base 功能，以该音频为参考生成自定义音色
3. 克隆出的音色 + 上方分场景情感指令一起使用，即可同时还原"声线"与"语气"
