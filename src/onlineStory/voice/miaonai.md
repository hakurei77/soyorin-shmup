# Qwen3-TTS 语音风格提示词

## 基础风格（Voice Design）
```
一位16岁左右的猫系少女，音色明亮偏沙哑，带一点野性的粗糙感。音调中高，音量偏大，语速快而冲，句尾常带短促的顿挫和上扬，像随时要扑出去打架。情绪外放，说话直来直去，没有敬语和修饰，透着不服输的倔强。喊"本小姐"时气势陡然拔高，但偶尔道谢时声音会突然变得很小、含糊不清，形成明显反差。
```

## 分场景情感指令（Emotion Control）

| 场景 | 提示词 |
|------|--------|
| 交谈1 | 理直气壮、满不在乎，语速快，带着"这有什么好问的"的不耐烦 |
| 交谈2 | 急躁催促，音调逐渐升高，尾音上扬 |
| 交谈3 | 前半句炸毛发飙、音量陡增，后半句突然压低嘴硬心虚，明显底气不足 |
| 闲置 | 拖长音抱怨，带一点撒娇式的威胁，懒洋洋但不耐烦 |
| 作战中1-4 | 高亢兴奋，喊叫式输出，带喘息感和笑意，像打得正开心 |
| 行动失败 | 前半句懊恼不甘、声音发闷，后半句恼羞成怒地拔高音量掩饰 |
| 问候 | 轻快熟络，毫无客气，后半句带期待感，尾音上扬 |
| 行动开始 | 自信爆棚的开战宣言，一字一顿有冲击力，结尾利落干脆 |

## 参数建议
- 语速：1.1x ~ 1.2x（偏快）
- 音调：+2 ~ +4（中高少女音）
- 情绪强度：高（作战中可拉满）
