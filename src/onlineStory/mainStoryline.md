# 主线剧情速览

258 年，希尔人撕裂两界壁垒入侵地球，蓝晶扰动场让人类武器体系全面失灵，三十年血战后战线陷入僵持。
在这个时代，**机娘无法独立作战**——她们的意识模型会持续积累错误，放任不管便会一步步走向崩溃，必须配备一名指挥官，定期接入脑机接口进行神经同步维护。这是刻在底层架构里的铁律，无人能够豁免。
你本是一名星际拾荒商人，偶然一次打捞出一座旧式休眠舱，唤醒了十年前失踪的军用原型机——**喵奈（P-07）**，从此与她结成搭档，开始了佣兵生活。

# 角色设定：喵浅

**喵浅**：舰船后勤官。玩家担任舰长，舰船由玩家与喵浅共同运营；喵浅统管后勤事务，包括补给、装备整备及舰上日常运转。玩家离舰期间，喵浅代为负责整艘舰船的管理。

# 剧情开始

【舱内，休眠舱开启的提示音回荡】

喵浅（查看面板，吹了声口哨）：激活完成，舰长。生命体征平稳，没有异常——哇哦，舱里是个机娘，还是个睡美人款。舰长你这一网下去，捞上来个大惊喜啊。

玩家（走近）：机娘？这种地方怎么会漂着一座休眠舱……是谁把她扔在这的。查一下她的编号。

喵浅（敲击终端，停顿）：……查不到。档案库里没有任何匹配记录，连休眠舱的制式都辨认不出来——看不出是军用的还是民间的，很老的型号了。（摊手）我只能说，舰长，你的运气一向这么玄学。上次捞到过期罐头，这次直接捞到个人。

【休眠舱内传来轻微的响动。喵奈缓缓睁开眼，瞳孔对焦了很久，才落在玩家身上。她下意识绷紧了身体，摆出戒备的姿态】

喵奈（声音沙哑，带着敌意）：……你是，谁。要打架吗。

玩家（举起手）：这艘船的舰长。你的休眠舱在星际空间里漂了很久，是我们把你打捞上来的。别紧张，我们没有恶意——也不打架。

喵奈（目光迟缓地扫过舱室，低头看向自己的手，戒备的姿态慢慢松了下来，没有回答）

玩家（放轻声音）：你沉睡了太久，需要先休息。喵浅，先扶她去宿舍吧。

喵浅（上前搀扶，笑嘻嘻）：来，睡美人，这边走。放心，本船宿舍的床可是舰长亲自挑的——虽然他砍价的水平比挑床的水平高多了。

【喵奈被喵浅搀扶去了宿舍】

# 第二段

【次日，宿舍】

喵奈（坐在床边）：……你说，现在是 287 年？

玩家：嗯。你的休眠舱至少在外面漂了十年。

喵奈（沉默良久）：十年……我只记得最后上了一艘运输舰，再之前的事，很多都碎了，拼不起来。

玩家：想不起来就别勉强。你先在这里安心休养，船上的事不用你操心。

喵奈（张了张嘴，半天挤出两个字，声音小得像蚊子哼）：……谢了。（立刻别过脸去）……别多想，基本礼貌而已。

【接下来的一个月，喵奈在船上静养。她的身体恢复得很快，但记忆始终残缺，偶尔会在走廊里怔怔地望着舷窗外的星空】

【某日，舰桥】

喵浅（调出体检报告，难得收起笑脸）：舰长，有件事得跟你正式说一下。她的稳态场数值在持续走低——照这个速度下去，她一个人撑不了太久。

玩家：什么意思？

喵浅：机娘从设计之初就不是能独立运转的兵器。她们的意识模型会持续积累错误——记忆错乱、逻辑冲突、感知失真，就像程序跑久了堆出来的 bug。放着不修，意识就会一步步崩溃，直到彻底失控。

玩家：没有修复的办法吗？

喵浅：有，而且只有一个——配备一名指挥官，定期接入脑机接口，通过神经同步帮她清理错误、校准稳态场。说白了，就是定期给她"修 bug"。所以每一台在役的机娘背后，都必须站着一名指挥官。

玩家：……每一个机娘都避免不了吗？

喵浅（点头）：每一个。这是刻在底层架构里的限制，谁都绕不开。没有指挥官的机娘，要么在崩溃前被回收，要么在失控后被击毁。（看向休眠舱的方向，声音放低）舰长，如果没人愿意成为她的指挥官……她独自存活不了太久。

喵奈（不知何时站在门口，轻声）：我听到了。……如果没有人愿意接手，我就自己想办法，不拖累你们。（顿了顿，低声）反正……我一个人也行。

玩家（沉默片刻，站起身）：我跑商跑了七年，攒下的也就这条船。但既然是我把你捞上来的——这个指挥官，我来当。

喵奈（怔住，耳朵抖了一下，随后别过脸去）：……随便你。（小声）又没人求你……笨蛋。

喵浅（在旁边憋笑）：哎呀，这就是所谓的"嘴上随便，耳朵倒是挺诚实"——

喵奈（炸毛）：你刚才什么都没看到！

【一个月后】

玩家：怎么样，休息的还好吗，身体上有没有什么不适？

喵奈：……没有。好得很。（顿了顿）别废话，听说今天要干正事？怎么个干法，跟谁打？

玩家：不打架。是同步维护。

喵奈（失望地耷下耳朵）：……哦。

喵浅（清了清嗓子，凑过来）：虚拟测试平台已经搭好啦。在你们第一次正式建立**共振链接**之前，先做个同步测试。那么，按惯例问一句——指挥官，你的驾驶经验是？

【弹出选项】
- **A：我是第一次操控机娘**
- **B：我是资深的指挥官**

### 选项 A：我是第一次操控机娘

喵浅（一副"果然如此"的表情）：也是，你跑了七年星际买卖，船上就咱俩，碰过机娘才怪呢。行，新手就要有新手的样子——接下来的测试就是为你准备的入门教程，跟着我的节奏一步一步来哦。（小声嘀咕）放心，出了事我会给你们收尸的，后勤保障嘛。

喵奈（小声）：第一次？……喂，可别把我玩坏了。

玩家（无奈地接上脑机接口）

喵奈（接上脑机接口，盯着玩家看了两秒）：……别拖我后腿。

（进入新手教学）

### 选项 B：我是资深的指挥官

喵浅（愣了一下，眯起眼睛）：……等等。资深？你？

玩家：有问题吗？

喵浅（绕着玩家转了半圈，上下打量）：当然有问题。你跑了七年商，这条船上就咱们两个人，你哪天接过脑机、哪天同步过机娘，我可是一笔一笔都记在账上的——你到底是什么时候学的？

玩家（沉默，没有回答）

喵浅（盯了半天，狐疑地收回目光）：……行吧，谁还没点秘密呢。（小声在小本本上记了一笔）"舰长，疑似隐瞒过往，待查"。那教程就免了，直接进入实战同步——我倒要看看你是不是真有两下子。

喵奈（半信半疑地打量着玩家）：……哼，老手可别中看不中用。

【跳过新手教学及测试剧情，直接进入后续章节】
