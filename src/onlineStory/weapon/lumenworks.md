# 流明光电（LumenWorks · LW）

## 公司风格说明

流明光电，星际时代最具代表性的电磁武器军工企业，轨道加速技术的绝对垄断者。

当磐舟重工还在锻造钨芯弹丸时，流明光电已经把电磁投射技术推到了物理极限。他们的武器不依赖火药与撞针，而是用层层叠叠的加速线圈，将弹芯在百分之一秒内推到数倍音速——安静、精准、致命。流明的装备是联邦正规军与精英佣兵团的标准配置，每一把出厂武器都印着那句著名的警告标语。

### 设计理念

- **速度即威力**：流明信奉动能的另一种解法——不是更重的弹丸，而是更快的弹丸。多级线圈加速 + 智能弹道修正，让每一发弹芯都以极限速度抵达目标。
- **精密即可靠**：全封闭式机匣、无尘车间装配、模块化线圈组。流明的武器像外科器械一样精密，战场上从不容许 0.1 毫米的误差。
- **秩序即美学**：纯白装甲板、锐利的橙色几何条纹、黑色警示标识——流明的视觉语言冷酷而秩序井然，一眼即知的军工血统。

### 企业文化

流明光电的厂训是：**"光速之下，众生平等。"**

他们的工程师鄙视火药武器是"会爆炸的烧火棍"，以自家武器"开火时只有线圈充能的低鸣"为傲。流明的标志——一道被几何折线框住的闪电状光束——喷涂在每一座军工船坞的外墙上，是联邦军火展上最令人敬畏的符号。

### 标志释义

流明光电的徽标由两个元素构成：中央是一道**折线化的闪电光束**，象征被科技驯服的极致速度；外围以**锐角几何框线**收束，象征秩序与精密。标志仅使用白、橙、黑三色——白色代表精密制造，橙色代表能量与警示，黑色代表军工的冷峻。

### 产品特点

| 维度 | 说明 |
| ---- | ---- |
| 结构 | 模块化电磁线圈组，全封闭机匣，精密工业装配 |
| 火力 | 超高速弹芯，穿透力与精准度兼备，军用级毁伤 |
| 射速 | 高射速脉冲连射，线圈预充能，射击间隔极短 |
| 外观 | 科幻工业风：白色装甲板 + 橙色几何条纹 + 黑色警示标识，锐利棱角 |

## 命名规范
- 格式：`LW-编号：名称`
- `LW` = LumenWorks（流明光电）
- 使用数字编号，如 `LW-01`
- 名称主题：以「光与天体」相关的外语词命名（薇丝珀、奥罗拉、赫利俄斯、泽尼斯……），呼应"流明"之光
