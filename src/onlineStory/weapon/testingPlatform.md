# 测试平台（Testing Platform）— 武器

## 公司风格说明

测试平台是一个由联合军械委员会主导的标准化武器研发项目，专注于**技术武器**（电磁投射类），旨在为星际殖民部队提供通用、可靠、易于改装的制式装备。

### 武器类型：技术武器 — 电磁投射

测试平台的所有武器均采用**线圈/轨道加速**原理：通过电磁场将实体弹芯沿导轨加速至极高初速后射出。与磐舟重工火药燃气驱动的传统动能武器不同，电磁投射武器的弹道更直、弹速更快、几乎没有后坐力——你可以把它理解为"一把没有后坐力的科幻化实弹枪"。

视觉上，这意味着每把测试平台武器都应能看到**裸露的电磁线圈环**或**轨道加速槽**沿枪管排列，线圈之间以暗色散热鳍片分隔，枪身集成小型电容模块。整体是「干净利落的科幻工业风」，而非磐舟那种「蒸汽朋克般的粗犷重工业」。

### 设计理念

- **标准制式**：测试平台武器采用统一的模块化架构，所有型号共享相同的导轨接口与附件规格。不同武器之间的配件可以交叉使用，极大降低了后勤压力。
- **电磁美学**：没有火药武器的抛壳窗和粗大炮管，取而代之的是沿枪管排列的线圈环、散热鳍片和电容模组。线圈间可有微弱的蓝色/青色指示灯条——仅在电容充能时亮起一道细线，非常克制，不是流光溢彩的能量武器。
- **改装友好**：每一把测试平台武器都预留了大量皮卡汀尼导轨空间，枪管线圈模组支持快速更换，握把底部可接入高容量电容弹匣或稳定支架。它是武器，更是一张任由枪匠挥洒的空白画布。

### 企业文化

测试平台的座右铭：**"你需要的，它都能装上。"**

联合军械委员会的设计哲学是：不给武器下定义，让使用者自己定义武器。测试平台的枪械出厂时只提供基础骨架——一套标准的电磁加速核心和导轨平台——而每一位士兵、佣兵、赏金猎人，都可以根据自己的任务需求，将它改装成独一无二的专属装备。

### 标志释义

测试平台的徽标由一个简洁的**六边形**外框与中心交叠的**线圈环**和**准星**图案组成。六边形代表标准化与模块化接口，线圈环象征电磁加速技术，准星则直指武器本身的用途。整体采用暗灰色调，接口节点以青色/橙色双色标识——青色代表电容充能状态，橙色标记导轨改装节点。

### 产品特点

| 维度 | 说明 |
| ---- | ---- |
| 结构 | 标准化模块架构，电磁线圈加速核心，导轨接口统一 |
| 火力 | 威力偏小但稳定，弹道笔直、弹速极快 |
| 射速 | 较快，无后坐力特性支持连续精准射击 |
| 外观 | 干净利落的科幻工业风，裸露线圈环 + 散热鳍片 + 电容模块，青色细线指示灯 |

### 与磐舟重工 (AH) 的风格对比

| 维度 | 磐舟重工 (AH) | 测试平台 (WPN) |
| ---- | ---- | ---- |
| 类型 | 动能武器（火药燃气） | 技术武器（电磁投射） |
| 风格 | 粗犷重工业美学 | 干净科幻工业美学 |
| 材质 | 厚重钢板 + 铆接装甲 | 轻质合金 + 聚合物 + 裸露线圈 |
| 色调 | 枪灰色，哑光 | 暗灰/消光黑，青色电容指示灯 |
| 核心视觉 | 炮管、抛壳窗、撞针 | 线圈环、散热鳍片、电容模块 |
| 定位 | "掉进泥里照样开火" | "没有后座的科幻实弹枪" |

## 命名规范
- 格式：`WPN-编号：名称`
- `WPN` = Weapon（武器），全称 Testing Platform Weapon（测试平台武器）
- 使用数字编号，如 `WPN-01`

WPN-01：新人手枪（Rookie Pistol）
WPN-02：新人霰弹枪
