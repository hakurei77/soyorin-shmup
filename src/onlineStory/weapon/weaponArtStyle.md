# 武器立绘 · 通用风格提示词（固定部分）

## 用法
发送给生图 AI 时：`具体武器提示词` + `下方通用风格提示词`，即可保证所有武器立绘风格统一。

## 通用风格提示词

```
2D游戏武器立绘，完整正侧面视图，横向构图，枪口朝右。武器严格水平放置，枪管轴线与画面底边完全平行，枪身绝对水平，无任何倾斜、无旋转、无透视角度，如同工程蓝图般的标准侧视图，武器所有结构完整入画不被裁切。
风格：赛璐璐平涂上色，粗黑轮廓线描边，简单的明暗二分阴影，轻微卡通化的比例夸张，干净的矢量感色块，无渐变堆砌，无写实材质渲染。
画面：纯白色背景，无投影无地面，武器悬浮居中，四边均匀留白。画面中只有武器本体，无人物、无手、无子弹、无特效、无文字水印。
```

## 武器提示词编写模板（供各公司参考）

每把武器的具体提示词只需包含三块：

1. **结构原型**：以某现实武器/某种机械为原型的基本布局（机匣、枪托、弹匣、导轨等）
2. **改造特征**：该公司风格下的结构改造（加粗、外露铆钉、能量回路、悬浮部件等）
3. **配色气质**：主体色 + 辅色 + 点缀色 + 做旧/崭新程度 + 一句话气质总结
