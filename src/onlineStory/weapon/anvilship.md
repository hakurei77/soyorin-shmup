# 磐舟重工（Anvilship Heavy Industries · AH）

## 公司风格说明

磐舟重工，一家固执得近乎浪漫的军工厂商。

在这个激光炮满天飞、粒子束武器已经成为制式装备的星际时代，当所有厂商都在比拼能量输出效率和光束聚焦精度时，磐舟重工依旧坚持使用最传统的动能方案——火药、电磁轨道、以及被加速到极致的实体弹丸。

### 设计理念

- **构造简单**：没有复杂的能量回路，没有精密的光学谐振腔。磐舟的武器拆开之后，往往只有一根炮管、一套供弹机构和一颗撞针。简单到任何殖民地机修工都能用扳手修好它。
- **威力巨大**：磐舟信奉一条古老的真理——没有什么目标是一发足够重的钨芯弹解决不了的。如果有，那就换更大的口径。他们的武器以单发毁伤力著称，命中即终结。
- **动能美学**：激光是优雅的、无声的、属于未来的；而磐舟的武器是粗粝的、轰鸣的、属于钢铁与火焰的。炮口的火光、弹壳抛出的脆响、弹丸撕裂装甲的钝音——这是独属于磐舟的美学，一种拒绝被时代驯服的工业浪漫。

### 企业文化

磐舟重工的厂训只有一句话：**"让弹丸飞一会儿。"**

他们的工程师嘲笑能量武器是"娇贵的玻璃艺术品"，而以自家武器"掉进泥里捡起来照样开火"为荣。在星际佣兵和边缘星系开拓者的圈子里，磐舟的标志——一座铁砧，砧上斜架起一根直指天空的炮管——就是"可靠"的代名词。

### 标志释义

磐舟重工的徽标由两个元素构成：下方是厚重的**铁砧**，象征锻造与坚不可摧的工业根基；上方以约 45° 角斜向升起的**炮管**（亦可看作一枚出膛的弹丸），象征动能武器永不低头的攻击姿态。整个标志采用单一的枪灰色，无任何渐变与装饰——正如他们的产品一样，去掉一切多余的东西，只留下钢铁本身。

### 产品特点

| 维度 | 说明 |
| ---- | ---- |
| 结构 | 极简机械结构，故障率极低，易于野外维护 |
| 火力 | 单发威力顶尖，穿透力极强，对重甲目标效果显著 |
| 射速 | 普遍偏低，强调一击必杀而非火力覆盖 |
| 外观 | 粗犷厚重，裸露的炮管与铆接装甲，不做任何多余的修饰 |

## 命名规范
- 格式：`AH-编号：名称`
- `AH` = Anvilship Heavy Industries（磐舟重工）
- 使用数字编号，如 `AH-01`
