《星夜弹幕》是一款东方风纵版弹幕射击游戏（STG），俯视角自机 + 鼠标瞄准射击，纯原生 Canvas 2D 实现，同屏 500+ 子弹稳定 60fps。

## 玩法

- 道中多波次敌机编队（直线 / 正弦 / 俯冲 / 追踪环绕等多种轨迹），清场后 Boss 登场
- Boss 多阶段符卡战：自机狙、扇形弹、旋转环弹自由叠加，击破或超时进入下一阶段
- 出击配置：多名可选角色与武器（突击步枪 / 激光 / 跟踪弹等），局内 1/2 键或滚轮切换武器
- 装备系统：武器、义体、技能（电磁脉冲 / 双子星卫 / 突触超频）自由搭配
- 模拟训练室：无限时木桩假人，自由测试装备与练习操作

## 操作方式

- 移动：WASD（键位可在设置中自定义并持久化）
- 射击：按住鼠标左键，自机始终朝鼠标方向旋转开火
- 低速精密移动 + 显示判定点：Z
- 闪现（Dash）：移动中按 Left Shift，3 格体力每 3 秒回复 1 格
- BOMB：X ｜ 暂停：Esc / P
- 帧率：30 / 60 / 120 / 144 / 跟随屏幕，可在标题界面设置
